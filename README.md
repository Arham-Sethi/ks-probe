# KS-Probe

Complete available first-party benchmark source, configurations, probes, provider adapters, scoring, orchestration and reporting scripts.

Start in [KS_Probe/README.md](KS_Probe/README.md); dependencies are in requirements.txt and pyproject.toml. Configure credentials outside source using the example environment file. Provider runs may incur costs; none were executed for this release.

Generated outputs and live/mock records are withheld pending provenance reconciliation. The manuscript is author-reported research, not a fresh reproduction of its experiments. The inspected scorer/parser assumptions are documented in the portfolio.
